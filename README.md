# People Service

**People Service** is a web application designed to help users search for blood donors near their location. Users must sign in to register as either a donor or a receiver of blood. The application allows users to search for donors based on their location and blood group, facilitating connections between those in need of blood and those willing to donate.

## Features

- User authentication with sign-in and sign-up functionality.
- Donors can register their details (name, blood type, location) after signing in.
- Receivers can sign in and search for blood donors based on location and blood group.
- User-friendly interface for seamless navigation.
- Contact feature for users to provide feedback.

## Technologies Used

- **HTML, CSS, JavaScript** for front-end development.
- **Node.js with Express** for server-side logic.
- **Mongoose** for managing data and interacting with MongoDB.
- Custom scrollbars and UI enhancements using CSS.
